# ChangThai-Zmittag

Kleine Handy-App für die Sammelbestellung beim Foodtruck ChangThai.

- Vornamen einmal erfassen, Menüs pro Person ankreuzen (Gericht, Fleisch/Vegi, klein/gross, Schärfe)
- WhatsApp-Bestellung an ChangThai mit einem Tipp öffnen
- Abrechnung mit Sammelkarten-Rabatt (teuerstes Menü gratis, anteilig verteilt, auf 5 Rappen gerundet)
- Betrag pro Person per WhatsApp oder SMS verschicken

Alle Daten bleiben auf dem eigenen Handy (im Browser-Speicher). Es gibt keinen Server.

## Installieren

Seite öffnen, dann:

- **iPhone (Safari):** Teilen → «Zum Home-Bildschirm»
- **Android (Chrome):** ⋮ → «App installieren» bzw. «Zum Startbildschirm hinzufügen»

Danach startet die App per Icon und funktioniert auch offline.

Inoffizielles Hilfsmittel, nicht von ChangThai.
